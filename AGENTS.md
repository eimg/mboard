# MBoard

Read [the product specification](PROJECT_SPEC.md) before changing keyboard behavior. Keep it aligned with implementation decisions and limitations. Use [the contributing guide](CONTRIBUTING.md) for tests.

On the maintainer’s Mac, follow `~/AGENTS.md` for developer network access and restoration. Preserve optional PATH settings. MBoard is native Swift/UIKit and requires no Fairway services.

Use a simulator for routine validation. Install on a physical device when the maintainer requests it.
