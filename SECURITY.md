# Reporting a security issue

If you find a way for MBoard to disclose typing, expose learned choices, or change text outside the intended selection, please report it privately. On GitHub, use **Security → Report a vulnerability** when that option is available. If you need a private contact, ask the maintainer for one without posting the vulnerability details.

Include the affected version or commit, the iOS version, the host app, and steps that reproduce the issue using invented text. Omit private messages, credentials, and signing files. Ordinary layout or suggestion-quality reports can follow the [contributing guide](CONTRIBUTING.md#report-a-typing-issue).
